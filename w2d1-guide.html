What You're Building

You're going to train a computer to sort real support messages into categories — the same kind of triage a real support team does every day, before a person even reads the message. You'll teach it by giving it examples of real tickets, sorted into the right category.

What Have You Done So Far?

You've started to train a computer to recognise the difference between technical problems, account and access issues, and general questions. These examples are being used to train a machine learning model — this is called ‘supervised learning’, because of the way you're supervising the computer's training. The computer learns from patterns in the examples you've given it: the words used, and how the message is phrased. Don't worry if your model gets things wrong early on — with only a handful of examples per category, it hasn't had much to learn from yet. A real support team's classifier would be trained on hundreds or thousands of real tickets.

❯ Tips

More examples!

The more examples you give it, the better the computer gets at recognising what tickets in the same category have in common.

Try and be even

Aim for roughly the same number of examples in each category. If one category has far more examples than the others, the computer may learn that category is simply more likely — which will skew its predictions, not just its accuracy.

Stuck for examples?

Think about real messages you've actually seen, sent, or heard about — or ask your team what's come up for their organisation. If you're genuinely stuck, that's exactly what the Stuck Protocol is for: try one strategy yourself, then ask a peer, then ask your coach.

What Have You Done?

You've trained a machine learning model to sort real support tickets into categories — genuinely the same kind of thing an AI & Automation Practitioner gets asked to build in a real workplace, just at a smaller scale. You've seen that doing this well takes real, balanced examples, and that a model is only ever as good as the data behind it. That's true for this classifier, and it's true for every AI tool you'll use from here on.
